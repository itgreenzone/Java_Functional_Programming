Records, Sealed Types & Patterns

Java 16 → Java 21 · results use the shared course dataset
course "today" = 2026-11-07

Key rules

  1. Records: validate and normalise in the compact constructor. 16
  2. One record per alternative; close the set with sealed … permits. 17
  3. Switch over a sealed type: every case, no default.
  4. Specific (guarded) cases before general ones (dominance).
  5. case null when null is possible. 21
  6. Record equals uses component equals: BigDecimal scale matters.
  7. getFirst/getLast/reversed (a view) over index maths. 21

Canonical snippets

1 · An algebraic data type
sealed interface PaymentResult
    permits Approved, Declined, Pending, Refunded {}
record Approved(String id, String m, BigDecimal amt)
