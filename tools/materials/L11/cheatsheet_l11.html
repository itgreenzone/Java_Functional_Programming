Grouping & Partitioning

Java 8 → Java 21 · results use the shared course dataset
course "today" = 2026-11-07

Key rules

  1. groupingBy(classifier) = Map<K, List<T>> in a HashMap, so the order is not defined. 8
  2. 3-argument form: groupingBy(k, TreeMap::new / EnumMap, downstream).
  3. Downstream = what to do with each bucket: counting, mapping, reducing, maxBy, joining…
  4. filter before grouping removes keys; filtering keeps them with 0. 9
  5. partitioningBy always has both keys, false first. 8
  6. maxBy gives an Optional; unwrap with collectingAndThen(…, o -> o.orElseThrow()).
  7. Several dimensions? Nested maps for drill-down, a record key for flat reports.

Canonical snippets

1 · Count per key, sorted
customers.stream().collect(groupingBy(
    Customer::city, TreeMap::new, counting()));
// {Bangkok=1, Colombo=1, Jakarta=2,
//  Kuala Lumpur=2, Singapore=4}
2 · Keep empty groups
groupingBy(Payment::method, TreeMap::new,
    filtering(p -> p.status() == FAILED, counting()))
// {CARD=0, PAYNOW=1, PAYPAL=1}
3 · Largest per key, unwrapped
groupingBy(Transaction::accountNumber,
    TreeMap::new, collectingAndThen(
        maxBy(comparing(Transaction::amount)),
        o -> o.orElseThrow().id()))
// {ACC-1001=T018, ACC-1002=T005, …}
