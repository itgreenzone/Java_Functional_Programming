Rule 1: associative

(a−b)−c ≠ a−(b−c)
reduce(0, a − b): seq −55,

Rule 2: true identity

x + id == x · id = 0, not 100
reduce(100, sum): seq 155,
parallel bigger 💥

3 forms

reduce(id, op) → T (empty: id) · reduce(op) → Optional (empty: empty) · reduce(id, acc, combiner) → U (Flight → seats 2078)
