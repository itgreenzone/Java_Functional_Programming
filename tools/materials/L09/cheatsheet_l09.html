Terminal Operations & Reduction

Java 8 → Java 21 · results use the shared course dataset
course "today" = 2026-11-07

Key rules

  1. One terminal op runs the pipeline. Pick it by the kind of answer: elements, one value, yes/no, one element. 8
  2. toList() is unmodifiable and allows nulls. Collectors.toList() makes no promise. 16
  3. forEachOrdered keeps encounter order in parallel; forEach does not.
  4. reduce: identity → T · no identity → Optional · 3-arg → U (with combiner).
  5. The operator must be associative and the identity neutral, or parallel breaks.
  6. Money: reduce(ZERO, BigDecimal::add), then divide(n, 2, HALF_UP). Guard empty.
  7. Empty stream: allMatch / noneMatch = true, anyMatch = false.

Canonical snippets

1 · Total balance (money)
accounts.stream().map(Account::balance)
        .reduce(BigDecimal.ZERO, BigDecimal::add);
// 300382.25
2 · Average premium, rounded
total.divide(BigDecimal.valueOf(n),
             2, RoundingMode.HALF_UP)
// 10826.50 / 10 = 1082.65
3 · Highest, any, first
txns.stream()
    .max(comparing(Transaction::amount))
// Optional[T049 7721.99]
accounts.stream()
    .anyMatch(a -> a.balance().signum() < 0)
// true (ACC-1013)
