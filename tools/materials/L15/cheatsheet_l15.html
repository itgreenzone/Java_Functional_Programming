Functional Programming Principles

Java 8 → Java 21 · results use the shared course dataset
course "today" = 2026-11-07

Key rules

  1. Pure core, I/O at the edges. Pass dates/Clock in; never now() in logic.
  2. Records are shallow: List.copyOf in the compact constructor. 16
  3. unmodifiableList is a view; List.copyOf is a copy. 10
  4. Withers return new values; no setters.
  5. Factories, currying and partial application replace flags and if/else.
  6. Compose: reduce(identity(), Function::andThen).
  7. Supplier = lazy. Memoize pure functions only; never recursive computeIfAbsent.

Canonical snippets

1 · Safe record
record Statement(String account, List<String> ids) {
  Statement { ids = List.copyOf(ids); }
}
2 · Curry and partially apply
Function<BigDecimal,
         Function<BigDecimal, BigDecimal>> fee =
    rate -> amount -> money(amount.multiply(rate));
var standard = fee.apply(new BigDecimal("0.0025"));
3 · A pipeline from a list of steps
steps.stream().reduce(Function.identity(),
                      Function::andThen);
