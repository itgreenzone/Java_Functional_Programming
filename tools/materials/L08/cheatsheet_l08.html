Sorting with Comparators

Java 8 → Java 21 · results use the shared course dataset
course "today" = 2026-11-07

Key rules

  1. sorted() = natural order: elements must be Comparable, else ClassCastException at run time. 8
  2. sorted(cmp) works for any type. Build cmp from keys, not hand-written compare. 8
  3. One key DESC? comparing(key, reverseOrder()). Not .reversed() at the end: it reverses the whole chain, nulls included.
  4. Nullable key → comparing(key, nullsLast(naturalOrder())).
  5. Enums sort by declaration order; BigDecimal by value (10.0 = 10.00).
  6. Sorts are stable; still end with a unique tie-breaker (id).
  7. User text → String.CASE_INSENSITIVE_ORDER.

Canonical snippets

1 · Ranking: tier DESC, total DESC, name ASC
comparing(CustomerView::tier, reverseOrder())
  .thenComparing(CustomerView::total, reverseOrder())
  .thenComparing(CustomerView::name);
// C003 PLATINUM 163950.25, C006 …, C010 GOLD …
2 · Nullable key, most recent first
.sorted(comparing(Activity::last,
                  nullsLast(reverseOrder()))
        .thenComparing(Activity::account))
3 · Map by value, top 3
map.entrySet().stream()
   .sorted(Map.Entry.<String, Long>comparingByValue(
            reverseOrder())
        .thenComparing(Map.Entry.comparingByKey()))
   .limit(3)  // [ACC-1003=7, ACC-1004=6, ACC-1008=6]
