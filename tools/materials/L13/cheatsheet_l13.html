Key rules

  1. Collector.of(supplier, accumulator, combiner, finisher, chars…). 8
  2. The combiner only runs in parallel: test sequential and parallel.
  3. iterate/generate are infinite: add limit or a predicate 9.
  4. In place, one by one: merge/compute. New map from a collection: a stream.
  5. Batches and windows: IntStream over indexes + subList.
  6. Running totals carry state: use a loop. Never mutate outside variables in map.
  7. Lazy paging: StreamSupport over an Iterator; short-circuit early.

Canonical snippets

1 · A custom collector
Collector.of(Acc::new, Acc::add, Acc::merge,
             Acc::finish, UNORDERED);
// count=12 sum=4429.84 … avg=369.15
2 · Chunks of n
IntStream.range(0, (list.size() + n - 1) / n)
  .mapToObj(i -> list.subList(i * n,
      Math.min(list.size(), (i + 1) * n)))
  .toList();   // 250 by 100: [100, 100, 50]
3 · Lazy paged stream
StreamSupport.stream(Spliterators
  .spliteratorUnknownSize(it, ORDERED), false);
