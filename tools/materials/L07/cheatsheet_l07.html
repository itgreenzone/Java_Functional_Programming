Filtering, Mapping & Slicing

Java 8 → Java 21 · results use the shared course dataset
course "today" = 2026-11-07

Key rules

  1. filter keeps elements where the predicate is true. Money: compareTo/signum, never equals (scale!). 8
  2. map: 1 in → 1 out (count and order unchanged). mapToInt/Long/Double for numbers; mapToObj/boxed back. 8
  3. flatMap: the function returns a Stream; all are merged. 1 → 0..n. 8
  4. mapMulti: push 0..n results into a consumer; no Stream per element. 16
  5. distinct uses equals/hashCode, keeps the first. Records just work. 8
  6. peek is for debugging only: count() may skip it. 8
  7. limit/skip slice by position; takeWhile/dropWhile by condition, on sorted input. 9
