Slicing ✂ position vs condition

Worked example: GOLD spending review

filter GOLD → flatMap accounts → flatMap txns → filter DEBIT > 100 → sorted newest → skip/limit → 11 matches = pages of 5, 5, 1 · page 1 starts T060 194.28

Which operation? 🤔

  • keep some → filter · keep a prefix of sorted data → takeWhile
  • change each → map (numbers: mapToInt) · each becomes many → flatMap / mapMulti
  • no duplicates → distinct · a page → skip + limit · just looking → peek

★ Remember

compareTo for money · map 1→1 · flatMap 1→many · mapMulti pushes · distinct needs equals · peek only to look · sort before limit/skip/takeWhile · next → L08 Sorting with Comparators
