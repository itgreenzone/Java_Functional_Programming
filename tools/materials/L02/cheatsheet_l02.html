Functional Interfaces: Rules and Standards

java.util.function · Java 8 → Java 21
examples use the shared course dataset

The SAM rule

  1. Exactly one abstract method = functional interface = can be a lambda or method reference target.
  2. Do not count: default 8, static 8, private 9 methods, and public Object methods (equals, hashCode, toString).
  3. Generic SAMs are fine: Converter<A,B> { B convert(A a); }
  4. @FunctionalInterface is optional: it adds a compile-time check and documents intent. Always use it on your own.
  5. Older SAMs work too: Runnable 1.0, Comparator 1.2, FileFilter 1.2, Callable 5.

Custom or built-in?

Write your own when

  • the name adds domain meaning
  • it must throw a checked exception
  • 3+ parameters (TriFunction)

Reuse built-in when

  • the shape is generic
  • it crosses APIs (streams, Optional)
  • it is local or numeric

Do / Don't

✔ Do

  • Annotate your SAMs
  • Role noun + verb: FeeRule.feeFor
  • Primitive types for numbers
  • Keep Functions pure

✘ Don't

  • Overload run(Supplier) + run(Callable): ambiguous
  • Add a 2nd abstract method
  • Function<T,Integer> in hot paths
