1 · SAM = Single Abstract Method

Counts: exactly 1 abstract method

Allowed, NOT counted:

  • default methods [8]
  • static methods [8]
  • private methods [9]
  • equals / hashCode / toString (Object's)

→ Comparator has compare + equals and is still functional.

2 · @FunctionalInterface = guard dog

Optional. But if someone adds a 2nd abstract method, it barks at the interface, not in 50 other files:

error: Unexpected @FunctionalInterface annotation

Standard: always put it on my own SAMs.
