Primitive Streams & Numeric Work

Java 8 → Java 21 · results use the shared course dataset
course "today" = 2026-11-07

Key rules

  1. Three primitive streams only: IntStream, LongStream, DoubleStream. 8
  2. range(1, 5) = 1..4 (half-open); rangeClosed(1, 5) = 1..5.
  3. sum() of nothing = 0; average/min/max of nothing = empty Optional.
  4. Need a Collector? boxed() or mapToObj first.
  5. Boxed values are objects: compare with equals, never ==.
  6. Money is never double. BigDecimal (scale 2, HALF_UP) or long cents.
  7. chars() gives ints (UTF-16 units); codePoints() gives real characters.

Canonical snippets

1 · Several statistics in one pass
flights.stream().mapToInt(Flight::seats)
       .summaryStatistics();
// count=8 sum=2078 min=160 max=471 avg=259.75
2 · Money total and average
var t = payments.stream().map(Payment::amount)
    .reduce(ZERO, BigDecimal::add);   // 4429.84
t.divide(valueOf(n), 2, HALF_UP);  // 369.15
3 · Character frequency
words.stream().flatMapToInt(String::chars)
     .mapToObj(c -> (char) c)
     .collect(groupingBy(identity(), TreeMap::new,
                         counting()));
