Stream Fundamentals

course "today" = 2026-11-07

Key rules

  1. Pipeline = source → 0..n intermediate → 1 terminal. 8
  2. Lazy: nothing runs until the terminal op. No terminal means no work at all.
  3. Vertical order (fusion): each element goes through the whole pipeline before the next one starts.
  4. Stateful barrier: sorted (and distinct) must see the input first; sorted holds everything.
  5. Short-circuit: limit, takeWhile, anyMatch, findFirst… stop early, so infinite sources are fine.
  6. One-shot: a second terminal call throws IllegalStateException. Keep the list or a Supplier<Stream>.
  7. Stores nothing and never modifies its source.
  8. parallel()/sequential() set one flag; the last call wins.
