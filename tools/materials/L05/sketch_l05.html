Optional · my notes L05

a box that holds 0 or 1 value · the return type says "maybe nothing"

Optional.of(x) x must not be null

Optional.ofNullable(x) null → empty

Optional.empty()

Optional.of(null) → NPE now!

✓ USE for

method return types where "no result" is normal:
findCustomer, findPolicy, latestTransaction

✗ NOT for

fields · parameters · Optional<List> · replacing every null

orElse = cook the backup meal ALWAYS · orElseGet = only if the fridge is empty

constant default → orElse("UNKNOWN") is fine · database / service / log / new object → orElseGet
