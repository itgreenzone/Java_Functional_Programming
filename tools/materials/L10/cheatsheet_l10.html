Collectors I: Collecting Results

Java 8 → Java 21 · results use the shared course dataset
course "today" = 2026-11-07

Key rules

  1. A Collector = supplier (new container), accumulator (add one), combiner (merge two), finisher. 8
  2. Type or order matters? toCollection(TreeSet::new). Never rely on toSet()/HashMap order.
  3. toMap(k, v) needs unique keys; otherwise give a merge function. Null values → NPE.
  4. 4th argument picks the map: TreeMap::new, LinkedHashMap::new, EnumMap.
  5. Money: reducing(ZERO, mapper, BigDecimal::add); never summingDouble.
  6. teeing = two collectors, one pass. 12
  7. Top level: prefer stream ops. Collectors shine as downstream (L11).

Canonical snippets

1 · Total per key with merge + sorted map
accounts.stream().collect(toMap(
    Account::customerId, Account::balance,
    BigDecimal::add, TreeMap::new));
// {C001=15700.50, C002=850.75, C003=163950.25, …}
2 · BigDecimal total as a collector
payments.stream().collect(
    reducing(ZERO, Payment::amount, BigDecimal::add));
// 4429.84
3 · Count and total in one pass
teeing(counting(),
       reducing(ZERO, Payment::amount,
                BigDecimal::add),
       CountAndTotal::new)
// 12 payments, total 4429.84
